# 演示视频

仓库内录像：[Web 用章申请端到端验收](demo/seal-approval-e2e.mp4)（约 4 分 32 秒，2560 × 1600，无配音）。

录像使用真实运行的后端、PostgreSQL 与 Web 页面，包含以下步骤：

1. 王工（`rd_emp_wang`）填写用章申请：选择合同章、文件名称、份数、用印日期及用途；展示必填项提示。
2. 提交前保存草稿、预览审批路径，确认提交后显示部门负责人李研为当前审批人。
3. 李研（`rd_head_li`）登录，填写部门审批意见并批准，申请转入钱会计的印章审核节点。
4. 钱会计（`fin_head_qian`）登录，核对申请内容，填写意见并批准。
5. 王工重新登录查看同一申请，状态为“已通过”，两级审批意见与日志完整，终态页面只有查看、刷新操作。

录像中的验收申请编号为 `ZD20261016000020`，标题为“端到端验收：研发合作协议用章”。该编号对应当前本地演示库；重新初始化数据库后，应按上述步骤生成新的申请。

演示账号密码均为 `Demo@2026`。本地启动方式和其他场景见[使用手册](user_guide.md)与[测试报告](test_report.md)。录像包含实际操作和等待过程。

移动 H5 另外验证了王工登录后收到该申请的完成通知、打开同一申请详情，以及个人统计图表正常绘制。录像使用本机直接运行的后端，未经过 Docker Compose；Compose 部署另行验收，见[测试报告](test_report.md)第 6 节。微信真机尚未验收。
