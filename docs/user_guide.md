## 2. 注册与登录

1. 登录页点“注册新账号”，填写用户名、姓名、邮箱、密码并选择申请加入的部门。
2. 提交后账号处于“待审核”，此时登录会提示“账号待管理员审核”。
3. 管理员在“注册审核”中通过后即可登录，系统自动授予“员工”角色。
4. 连续输错密码会临时锁定账号；忘记密码由管理员在“用户管理”中重置，登录后在“个人信息”（移动端“我的 → 修改密码”）中修改。

登录状态保持 7 天；访问令牌 30 分钟自动续期，无需重新登录。

## 3. 员工：发起与跟踪申请

### 3.1 发起申请

“发起申请”（移动端底部“发起”）列出本部门可用的模板：

| 类型 | 主要内容 | 审批路径 |
|---|---|---|
| 采购申请 | 采购明细（数量 × 单价自动合计）、至少两家供应商报价（线上报价需链接和截图，线下报价需附件或说明）、拟选报价、预算上限、期望到货日期；单一来源需说明理由 | 部门负责人 → 财务预算审查 → 企业负责人（金额 ≥ 5 万元时） |
| 差旅申请 | 出发地、目的地、起止时间（自动计算自然日天数）、交通方式、事由、预算、同行人员 | 部门负责人 → 企业负责人（预算 ≥ 2 万元或超过 7 天时） |
| 报销申请 | 费用明细（类型、日期、用途、金额、票据）；可关联本人已通过的差旅 / 采购单，否则填写独立报销说明；无票明细需说明原因 | 部门负责人 → 财务审核 → 企业负责人（金额 ≥ 1 万元时） |
| 自定义申请 | 按管理员设计的表单填写，如请假、用章 | 按模板配置 |

- 草稿随时保存，未填完也可以保存；提交时才做完整校验，出错的字段标红并提示原因。
- 提交前显示“审批路径预览”：每个节点的审批人，以及因条件不满足而跳过的节点。
- 金额精确到分，合计由系统按明细重算。
- 附件支持 JPG、PNG、PDF，单个不超过 10 MB；系统按文件内容识别类型，改扩展名的可执行文件会被拒绝。
- 如果你是本部门负责人，第一个审批节点会自动交给替代审批人（不能自己批自己的单），路径预览中会注明。

### 3.2 我的申请

- 列表可按状态、类型、日期、关键字筛选，状态列显示当前停在哪个节点。
- 详情页显示业务内容、附件、流程时间线（每个节点的审批人、意见、时间，跳过的节点灰色并显示条件）和审批日志。
- 审批中：可以“撤回”，或“催办”（按四小时冷却时间档限频；详情页显示冷却状态，冷却结束后可再次催办，审批人收到站内通知和邮件）。
- 已驳回、已撤回：可以“复制为新申请”，按当前模板生成新草稿；不再符合当前规则的日期、选项、正则或附件规则字段会清空，需要重新填写，已停用的同行人不会复制。复制不会修改源申请或其审批记录。
- 复制仍按当前系统的附件数量和总大小上限检查；管理员降低限额后，超限旧单可能无法整单复制，此时可新建草稿并选择限额内的附件，或联系管理员核对限额。
- 草稿可以编辑、删除。

## 4. 审批人：处理待办

1. “我的待办”（移动端“待办”）列出分配给你的任务，可按类型、关键字筛选，超时的任务会标出。
2. 打开任务查看申请详情，选择“通过”（可填意见）或“驳回”（必须填写 5–500 字理由）。
3. 会签节点需所有审批人通过；或签节点任意一人通过即可，其余人的待办自动取消。
4. 若申请已被撤回或待办已被处理，系统提示“申请状态已变化”，刷新即可，不会重复审批。
5. “我的已办”查看处理过的任务。

部门负责人还可在“本部门申请”中查看本部门的申请；获得授权的用户可在“授权范围申请”中查看授权部门的申请。附件和他人的审批意见按权限显示。

## 5. 通知

- 页面右上角铃铛（移动端“消息”）显示未读数，新消息实时推送，无需刷新。
- 通知类型：新待办、节点通过、申请通过 / 驳回、待办被取消或转办、催办、超时提醒、注册审核结果。
- 点击通知跳转到对应申请；可单条或全部标为已读。
- 在“个人信息”中可以关闭邮件提醒（站内通知不受影响）。

## 6. 统计

| 统计 | 谁能看 | 内容 |
|---|---|---|
| 个人 | 所有员工 | 各状态申请数、已通过金额、待办数 |
| 部门 | 部门负责人（本部门） | 按类型、按月的数量与金额，通过率，平均审批时长 |
| 财务 | 有财务统计授权的用户 | 按费用类型、部门汇总报销金额 |
| 企业 | 企业负责人或有全部范围授权的用户 | 各部门对比 |

统计按提交时间和提交时所在部门计算；通过率只计已结束的申请。

## 7. 系统管理员

| 菜单 | 功能 |
|---|---|
| 用户管理 / 注册审核 | 审核注册、启用停用、调整部门、授予回收角色、设置主办人、重置密码、解锁、强制下线 |
| 部门管理 | 新增、修改、删除部门，设置部门负责人（自动同步“部门负责人”角色） |
| 角色与权限 | 查看内置角色及其权限点 |
| 授权管理 | 给用户授予数据范围（查询申请 / 财务统计 / 业务内容，指定部门或全部，可设有效期），可回收 |
| 流程模板 | 新建自定义模板；编辑时生成草稿版本，设计表单字段（文本、数字、金额、日期、单选、附件）和审批节点（部门负责人 / 角色 / 指定用户，单签 / 会签 / 或签，条件与超时），校验通过后填写变更说明发布。已提交的申请继续按提交时的版本流转 |
| 费用类型 | 新增、停用报销费用类型（被引用后不能删除） |
| 系统配置 | 兜底审批人、附件数量与大小上限、超时提醒时限、是否发送邮件 |
| 待办监控 | 查看待办的元数据和超时情况，必要时填写原因转办给他人 |
| 审计日志 | 管理操作的前后差异，以及管理员查看业务数据的记录 |
| 邮件投递 | 邮件发送状态与重试情况 |

管理员没有审批权限，也不能打开员工申请的业务正文。

## 8. 常见提示

| 提示 | 含义与处理 |
|---|---|
| 草稿已在别处修改，请刷新后重试 | 同一草稿在另一个窗口保存过，刷新后再改 |
| 申请状态已变化，请刷新后重试 | 申请已被撤回、批准或驳回 |
| 模板已更新，请按新版本确认后重新提交 | 自定义申请的模板发布了新版本，表单按新版本重新显示，确认后再提交 |
| 文件类型不允许 | 只能上传 JPG、PNG、PDF |
| 资源不存在或无权查看 | 无权访问该申请或附件 |
