# 界面设计规范：案卷（第二版）

本文是 Web 端（`frontend/`）界面的设计依据；颜色、字号、圆角等一律用 token，不在组件里写死色值。静态样稿见 `docs/ui_v2_mockup.html`（用浏览器打开，每屏 1440×900），实现时以本文为准、样稿为参照。

移动端（`mobile/`）本轮不改，仍按第一版「流转单」规范（第 9 节）；Web 定稿后再同步。

## 1. 设计立意

第一版借用了纸质呈批单（单据头、签批栏、盖章），方向没错，但做出来是三层灰（侧栏灰、底色灰、面板白）叠在一起，Element Plus 的默认表格和卡片原样露出，看起来像没上色的线框图。第二版保留单据语汇，把画面重新组织成一张办公桌：

- **桌面**：页面底色比第一版深一档，铺着会动的格纸点阵。桌面上只放东西，不放字（页面标题、页签除外）。
- **单据**：列表、表单、详情、统计都是放在桌面上的白纸。**白色只给单据**，顶栏除外，别处不出现大块白底。
- **案卷页签**：同一栏目下的几个视图（我的待办 / 我的已办 / 本部门申请）做成档案夹的索引页签，插在单据上沿；选中的页签是白的，和下面的单据连成一张纸。
- **签批栏与章**：仍是唯一的视觉重点。签批栏改成横贯单据的一整行表格格子，像印好的表单。

一条贯穿全站的规则：**选中即相连**。当前所在的顶栏栏目和桌面连成一片，当前页签和单据连成一片；不用下划线、不用色块高亮来表示「当前」。

## 2. 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `desk` 桌面 | `#E6E9E5` | 页面底色、顶栏选中栏目的底 |
| `desk-dot` 格点 | `#BFC6BF` | 格纸点阵 |
| `sheet` 单据 | `#FFFFFF` | 单据、顶栏、浮层 |
| `tab` 页签 | `#D9DED9` | 未选中的索引页签 |
| `row-hover` | `#F3F5F2` | 列表行悬停底、表头之外的浅底（如合计行） |
| `ink` 墨 | `#1E2B36` | 正文、标题（蓝黑墨水色，不用 #111 一类的近黑） |
| `ink-2` | `#55636D` | 次要文字、字段名；**桌面上的文字至少用这一级** |
| `ink-3` | `#69757D` | 辅助文字、时间，只用在白底上，最小 12px |
| `rule` 线 | `#DDE1DC` | 单据内分隔线、单据边框 |
| `rule-strong` | `#BEC5BE` | 输入框边框、表头下线、签批栏格线 |
| `primary` 蓝黑 | `#2F4E6B`（悬停 `#263F57`，浅底 `#E8EEF3`） | 主操作、链接、审批中、当前签批格 |
| `success` 苔绿 | `#3F6E4E` / 浅底 `#E9F1EB` | 已通过、同意章 |
| `danger` 赭 | `#9A4337` / 浅底 `#F6EBE9` | 已驳回、驳回章、删除、通知角标 |
| `warning` 土黄 | `#94702A`（文字 `#775A1E`，描边 `#D8C59A`）/ 浅底 `#F5F0E4` | 已超时、无票明细 |
| `muted` 灰 | `#78838A` | 草稿、已撤回、已取消 |

- 状态映射不变：草稿 = muted，审批中 = primary，已通过 = success，已驳回 = danger，已撤回 = muted。
- Element Plus 的 `--el-color-*-light-N` 按组件库的规则从上表推出：`light-N = mix(色, #FFF, N×10%)`，`dark-2 = mix(色, #000, 20%)`。
- 图表序列色：`#2F4E6B` `#3F6E4E` `#94702A` `#9A4337` `#78838A` `#8A9FB3`。状态分布图按状态语义取色，已撤回用 `#8A9FB3`，免得和草稿连成一片灰。
- 文本选中：`rgba(47, 78, 107, 0.16)`。

## 3. 字体与字号

- **宋体（标题与大数字）**：自托管 Noto Serif SC 600（`@fontsource/noto-serif-sc`，按 unicode-range 分片，只加载用到的字），回落 `"Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", serif`。只用于：页面标题、单据标题、工作台问候、登录 / 注册标题、单据头和工作台的大金额、章上的字、发起申请入口上的单据名。
- **无衬线（其余一切）**：系统字体 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Noto Sans CJK SC", system-ui, sans-serif`。
- **数字**：金额、单号、计数、日期一律 `tabular-nums`；金额右对齐；单号不用等宽字体。
- **字号阶**（px）：12 辅助 / 14 正文 / 16 小节标题、单据名 / 20 / 26 单据标题 / 32 页面标题与问候。正文行高 1.65，标题 1.3。小节标题 16px 600 无衬线。
- 不用全大写标签，不在标题上方加小标签，标题里不单独给某个词换色或加粗。

文案规则（沿用并收紧）：

- 不用「A · B · C」中点拼接，用间距分开。
- 链接、按钮不加「→」；写清动作：「查看全部待办」「处理」「填写申请」。按钮文字与结果提示一致（「同意」→「已同意」）。
- 说明文字能删就删；需要时写短、写平，从使用者角度说。不写排比和自夸（「高效便捷」「一目了然」「逐级流转」）。
- 空状态写清下一步，并给出按钮：「暂无草稿」+「填写申请」。不用 Element Plus 默认的空盒子插画。

## 4. 形状与层次

- 圆角分级：单据 6px；页签上两角 6px；按钮、输入框、发起入口 4px；标签 2px；头像圆形。
- 单据：1px `rule` 边框 + `0 1px 0 rgba(30, 43, 54, 0.05)`（纸的厚度），不用模糊阴影。浮层（下拉、对话框、通知、抽屉）用 `0 8px 24px rgba(30, 43, 54, 0.14)`。
- 单据之间、单据与页面标题之间的间距 24px；单据内边距左右 24px（详情页 32px）。
- 状态在列表中用「6px 圆点 + 文字」；已超时用 `warning` 描边小标签。
- 焦点：`:focus-visible` 统一 2px `primary` 外框，偏移 2px。

## 5. 布局

### 5.1 外壳：顶栏（取代侧边栏）

```
┌────────────────────────────────────────────────────────────────────────┐
│ [审] 企业审批   ╭工作台╮  申请   审批 4   统计   管理        🔔31  (李) 李研 ▾ │ 56px 白底，底部 1px rule
└────────────────╯      ╰───────────────────────────────────────────────┘
   桌面（desk + 格纸）                                         选中栏目和桌面连在一起
```

- 栏目由 `router/menu.ts` 的分组而来：工作台 / 申请 / 审批 / 统计 / 管理；按权限过滤，组里一项都看不到的栏目不显示。通知中心不单列栏目，从铃铛进入。
- 栏目项高 44px、贴着顶栏下沿，左右内边距 18px，15px `ink-2`。悬停：文字 `ink`、底 `row-hover`。**选中**：底色 `desk`、上两角 8px、文字 `ink` 600，并盖住顶栏下沿那 1px 线，看起来是从桌面伸上来的页签。
- 「审批」栏目旁显示待办数（12px `primary` 600，0 时不显示）。
- 品牌：28px 方框「审」（宋体 700、1.5px `primary` 描边、4px 圆角）+「企业审批」（宋体 600 17px）。
- 右侧：通知铃铛（未读角标 `danger`）、头像 + 姓名，点开为个人信息 / 退出登录。
- 内容区：`max-width: 1280px` 居中，内边距 32px 40px 40px，格纸铺满整个桌面（不受 1280 限制）。
- **窄屏（< 768px）**：顶栏只留品牌、铃铛、头像和左侧菜单按钮；栏目和子页面放进左侧抽屉，抽屉里按栏目分组列出全部页面。

### 5.2 案卷页签（栏目下的子页面）

```
  ╭我的待办 4╮╭我的已办╮╭本部门申请╮                       [刷新]
──╯          ╰┴────────┴┴──────────┴─────────────────────────────
│ 单据（白）                                                     │
```

- 有并列子页面的栏目（申请：发起申请 / 我的申请 / 本部门申请 / 授权范围申请；审批：我的待办 / 我的已办；统计：个人 / 本部门 / 全企业；通知：全部 / 未读）用页签当页面标题，**不再另放 32px 大标题**。页签是路由链接（或页内切换），可 Tab 聚焦。
- 页签：内边距 9px 20px，14px；未选中底色 `tab`、文字 `ink-2`，悬停文字 `ink`；选中白底、文字 `ink` 600、1px `rule` 边框且无下边，盖住单据上沿，单据左上角圆角取消。页签之间 4px。
- 页面右上的操作（刷新、查看已办等）和页签同一行、右对齐。
- 「管理」栏目子页面多（11 个），改用单据左侧的竖向索引：一列 200px 的页签竖排在单据左边，按「人员（注册审核、用户、部门、角色与权限、授权）/ 流程（流程模板、费用类型、待办监控）/ 系统（系统配置、审计日志、邮件投递）」分三段，段名 12px `ink-2`；选中项白底、和右侧单据连成一片（去掉右边框）。
- 没有并列子页面的页（个人信息、无权访问、404、模板设计器）用 32px 宋体页面标题。

### 5.3 列表（登记簿）

全站列表统一改造 `el-table` 的外观（全局样式），不再用灰底表头、竖线和空列：

```
  申请                               申请人   当前节点       金额     提交时间
  ─────────────────────────────────────────────────────────────────────────── rule-strong
▌ 列表操作验证-催办 [已超时]          王工     部门负责人审批   无     2026-10-17 09:12   [处理]
  请假申请　ZD20261017000031         研发部
  ─────────────────────────────────────────────────────────────────────────── rule
```

- 表头：白底、12px `ink-3` 500，下边 1px `rule-strong`；无竖线、无斑马纹。
- 行：上下内边距 14px；首末列内边距 24px 与单据对齐；行间 1px `rule`。
- **两行单元格**合并信息，减少列数：「申请」列第一行标题（14px `ink` 500，已超时标签跟在后面），第二行「类型　单号」（12px `ink-3`）；「申请人」列第二行写部门。不出现只写「—」的整列；没有金额的申请金额列写「无」（`ink-3`）。
- 标题列吃掉剩余宽度（`min-width` 而不是固定 `width`），其余列按内容给定宽度，避免像现在这样标题和审批节点被截断。
- 悬停：整行底色 `row-hover`，首列左侧 3px `primary` 竖线，行尾显出行内操作（处理 / 查看 / 催办）。键盘聚焦和 `(hover: none)` 时行内操作常显。不再用 Element Plus 的固定列（fixed 列的阴影很脏）。
- 工具栏（搜索、筛选）在单据内顶部，内边距 16px 24px，下边 1px `rule`；分页在单据底部，右对齐，13px `ink-2`。
- 我的申请的状态筛选（全部 / 草稿 / 审批中 / 已通过 / 已驳回 / 已撤回）放在工具栏里，做成一排带数量的文字筛选，选中项 `ink` 600，前面带该状态的圆点颜色。

### 5.6 表单（发起 / 编辑）

- 整个表单是一张单据：顶部单据头（宋体 26 的申请类型名 + 一行 14px `ink-2` 说明，草稿时右上角显示「草稿」描边小框和单号），下面按小节分段，小节之间 1px `rule`，小节标题 16px 600。
- 字段标签在上、输入框在下（不再左右排），两列网格，长文本和明细表独占一行；必填星号用 `danger`。
- 输入框高 36px，1px `rule-strong`，悬停 `ink-3`，聚焦 `primary` 边框 + 2px `primary` 15% 外发光。
- 明细表、报价表用登记簿样式；合计行底色 `row-hover`，金额宋体 600 右对齐。
- 底部操作栏同详情页：左「返回」，右「保存草稿」「提交」。

### 5.7 统计

- 页签：个人 / 本部门 / 全企业（按权限）。日期区间与刷新在页签同一行右侧。
- 顶部一张单据做「账单行」：3 到 4 个指标横排，指标名 12px `ink-3`、数值宋体 32、单位 14px `ink-2`，指标之间 1px 竖线，不做成一排小卡片。
- 图表各占一张单据；空数据时写清原因和下一步，不画空盒子。

### 5.8 登录 / 注册

- 左半边是桌面（格纸会动），左上角品牌；中间放一张完整的样例单据（520–560px 宽）：单据头（采购申请、单号、标题、申请人、金额）+ 三格签批栏，签批栏按第 6 节「流转演示」自动走流程。下方一行 12px `ink-2`：「审批流程」。
- 右半边白底表单，宋体 28「登录」，标签在上，输入框高 40px，主按钮通栏高 42px。演示账号区块样式随之调整。

## 6. 交互

### Web：鼠标

1. **列表行**：整行可点进入详情，`cursor: pointer`；悬停效果见 5.3。按住 Ctrl / ⌘ 或中键点击在新标签页打开。
2. **签批栏与流转记录联动**：鼠标移到某个签批格，下方流转记录中属于该节点的条目高亮并弹出审批意见；反过来移到流转记录条目上，对应签批格高亮。
3. **单号复制**：悬停单号出现「复制」提示，点击复制并提示「已复制单号」。
4. **发起入口**：悬停边框变 `primary`；按下下沉 1px。
5. **附件区**：把文件拖进上传区，拖入时虚线框变 `primary`、底色 `primary-tint`。
6. **统计图表**：悬停显示数值；悬停图例高亮对应序列，其余淡出。

### Web：背景「格纸」

格纸只铺在桌面上（顶栏下的整个内容区和登录 / 注册页左半边），单据盖在上面。行为沿用现有实现（`composables/paperMath.ts`、`usePaperField.ts`），只改颜色：

- **点阵**：间距 20px，点半径 1px，颜色 `desk-dot`。每个点围绕自己的格点独立做布朗运动（Langevin 步进 + 弹簧回拉，σ≈3px），整片不出现成片的波浪。
- **光标**：半径 140px 内的点更活跃、变大到 1.8px、颜色向 `primary` 过渡；光标附近一层很淡的径向亮光，亮光颜色取 `sheet` 白、透明度 ≤ 0.35。离开区域时影响 300ms 内淡出。
- **点击涟漪**：在桌面空白处按下，点阵从按下点荡开，参数不变（最多 3 个同时存在）。
- **性能与降级**不变：静止时停帧、页面不可见时停止；`(hover: none)`、`(pointer: coarse)`、`prefers-reduced-motion: reduce` 只画静态点阵。

### Web：登录页「流转演示」

样例单据里的三格签批栏（部门负责人、财务审批、企业负责人）自动循环四步，每步 2400ms：① 部门负责人「处理中」，其余「未到」；② 部门负责人「同意」，财务「处理中」；③ 前两格「同意」，企业负责人「处理中」；④ 三格全部「同意」，单据头右上落一枚「已通过」章（与详情页终态章同款）。第 ④ 步停 3200ms 后淡回 ①。

- 格子样式与详情页签批栏完全一致（可直接复用组件或样式）。
- 鼠标在单据上时暂停；移到第 i 格立刻切到「第 i 格处理中」；移开后从当前步继续。
- 单据本身对读屏隐藏（`aria-hidden`），说明文字可读。`prefers-reduced-motion: reduce` 时不自动播放，停在第 ②步；页面不可见时暂停；卸载时清理计时器。

### Web：登录页分栏可拖动

不变：分界线两侧 6px 热区、`col-resize`；悬停 / 拖动时 2px `primary` 线 + 4×28px 握把；表单栏 380px 到视口 60%，左栏不小于 360px；宽度存 `localStorage`（`eas.auth.formWidth`），双击恢复 540px；方向键 16px、Home / End；880px 以下只显示表单栏。

## 7. 动效

- 只有四类：对操作的回应（展开、收起、选中、拖动、回弹）、格纸、登录页流转演示、盖章。不做页面载入动画、卡片悬停浮起、逐个淡入。
- 时长 120–240ms，缓动 `cubic-bezier(0.2, 0, 0, 1)`。
- 盖章：1.15 倍缩到 1 倍、透明度 0 → 1，240ms，只播一次。
- `prefers-reduced-motion: reduce` 时所有过渡瞬时完成，章直接显示。

## 8. 质量底线

- 对比度：正文 ≥ 4.5:1（`ink` 在白底约 14:1，`primary` 约 8.5:1）；`ink-3` 只在白底用；桌面上的文字至少 `ink-2`。
- 可点元素 ≥ 32px；768px 以下切抽屉菜单，列表行内操作常显。
- 所有自建可点元素用 `button` / `a`，或补齐 `tabindex` 与回车 / 空格。
- 1280、1440、1920 宽和 375 宽下都不出现横向滚动条（签批栏、宽表格在单据内部横向滚动除外）。
