# 界面设计规范：套色（第三版）

本文是 Web 端（`frontend/`）界面的设计依据。颜色、字号、圆角、投影一律用 `frontend/src/styles/tokens.css` 里的 token，不在组件里写死色值。静态样稿见 `docs/ui_v3_mockup.html`（用浏览器打开，每屏 1440×900，背景会动），实现时以本文为准、样稿为参照。全局组件样式和外壳的用法见 [套色 v3 基础层](ui_v3_foundation.md)。

移动端（`mobile/`）本轮不改，仍按第一版「流转单」规范（第 9 节）。

## 1. 设计立意

风格取自 1950–60 年代美国的广告插画、绘本和国家公园海报（中世纪现代主义插画）：几块平涂的颜色、四五种墨印在暖白纸上、细颗粒、几何化的造型、单层硬边阴影、海报式构图。

**风格贯穿整套界面，不只在插画里。** 单据、按钮、页签、标签、输入框、图标、字体和数字都要像是和插画用同一套网版印出来的。插画只放在有空间、有理由的地方（登录页、工作台横幅、发起申请入口、空状态、403 / 404），其余页面靠组件本身的样式带出风格。

之前被否掉的做法（不要再走回去）：

- 手写 SVG 拼出来的场景（矩形 + 圆）显得粗糙。场景插画一律用生成的位图（提示词在 `frontend/src/assets/illustrations/prompts/`）。
- 五种墨大面积铺满（整条深色侧栏、整排彩色入口）没有主次。纸和藏青是主色，其余的墨只以小块实色出现。
- 只有插画好看、组件还是普通的细线框按钮，等于没换风格。
- 草丛贴图逐行错开做「随风摆」显得廉价。风只吹在背景画里的草地上（着色器），能单独动的只有飘叶。

| `sage` 鼠尾草 | `#A3B590`（文字 `#3F5A38`，浅 `#E2E9D6`） | 已通过 |

- 状态映射：草稿 = 暗纸，审批中 = 天青，已通过 = 鼠尾草，已驳回 = 铁锈，已超时 = 芥黄，已撤回 = muted。状态一律做成**实色胶囊**（`el-tag` 已全局改好），色块上的字：天青 / 鼠尾草 / 芥黄 / 暗纸用 `ink`，铁锈用 `sheet`。
- 浅色都是墨和纸调出来的（`light-N = mix(色, sheet, N×10%)`），不掺白；改了基础色运行 `node scripts/generate-theme-colors.mjs --write`。
- 图表序列色：`#27425A` `#7F9A6E` `#D9A441` `#A94A2C` `#9A9488` `#8FB0BF`（`--eas-chart-1..6`）。
- 颗粒：有颜色的墨块（主按钮、标签、计数、章、选中的胶囊）叠 `--eas-grain`（`background-blend-mode: multiply`），纸色块和文字不加。工具类 `.inked`。

## 3. 字体与字号

- **展示字**（`--eas-font-display`）：数字和拉丁字母取 Fraunces（柔角轴 `SOFT 100`，600），中文落到站酷小薇。用于页面标题、单据标题、小节标题、问候、大金额、计数角标、章上的字、发起入口上的单据名。站酷小薇字身窄，标题统一加 `letter-spacing: var(--eas-display-tracking)`（-0.06em）。v2 的 `--eas-font-serif` 已指向展示字。
- **正文**：系统无衬线 `--eas-font-sans`。表单、表格、说明文字都用它。
- 数字：金额、单号、计数、日期 `tabular-nums`；金额右对齐。列表里的金额用展示字 16px，单据头的金额展示字 44px。
- 字号阶（px）：12 辅助 / 13 注释 / 14 正文 / 16 / 20–21 小节标题 / 28 单据标题 / 32 / 40 页面标题（窄屏 32）/ 44–52 问候、登录标题、单据头金额。

文案规则（沿用）：不用「A · B · C」中点拼接；链接和按钮不加「→」，写清动作；说明文字能删就删，不写排比和自夸；空状态写清下一步并给按钮。

## 4. 形状、投影与「错版」

- 圆角按角色分：单据 16、输入框 12、浮层 14、对话框 18、按钮 / 页签 / 标签 / 计数都是胶囊、头像和章是圆。
- 投影一律是**硬投影**（0 模糊，往右下错开）：单据 `6px 6px 0 shade`；纸色按钮 `3px 3px 0 shade`；有色按钮用同色深一档（藏青用 `ink-deep`、芥黄用 `mustard-deep`、铁锈用 `rust-deep`）；浮层 `6px 6px 0` 半透明墨 + 1px 框。不用任何模糊阴影。
- 按钮悬停抬起 1px（投影变 4px），按下沉进投影（投影 1px）。
- **错版**是「选中 / 聚焦」的专用记号：在元素后面错开垫一块芥黄（`--eas-offset-mark: 3px 3px 0 mustard`）。用在：选中的胶囊页签、选中的管理索引项、聚焦的输入框、当前签批格、当前页码、悬停的发起入口插图、品牌章、空状态插画的圆。不要拿它做装饰。
- 顶栏当前栏目：字后面垫一块手刷形状的芥黄浅墨斑（不规则圆角 + 轻微旋转）。
- 单据内分段用 2px 虚线（`rule`），像裁切线；不用实线描边单据。
- 小节标题前可放一个两色叠印小图形（`.ink-glyph--sun / leaf / hill / bell / stack`），每张单据最多一个。

## 5. 布局

### 5.1 外壳

```
 (审) 企业审批   [工作台]  申请  审批 ④  统计  管理                   (🔔) (李) 李研 ▾
                  ↑ 芥黄墨斑
 审批                                                   ← 栏目名，展示字 40
 (我的待办 ④) (我的已办) (本部门申请)                      [刷新]
 ┌───────────────────────────────────────────────────────┐╮ 单据：纸色 + 硬投影
```

- 顶栏不另起白带，和页面同底，高 72px；品牌是铁锈圆章（展示字「审」+ 芥黄错版）+「企业审批」展示字 21。
- 有并列子页面的栏目：外壳在内容上方渲染**栏目名大标题 + 一排胶囊页签**（`SectionTabs`），页面操作通过 `#section-actions` 放到页签同一行右侧。单据和页签不再相连。
- 管理栏目：左边 200px 竖排胶囊索引（分组名用展示字），右边一张单据，中间 28px。
- 内容区最大宽 1280，左右 48。窄屏（< 768）顶栏只留菜单按钮、品牌、铃铛、头像，栏目和子页面放进抽屉。

### 5.2 背景（PC 鼠标互动）

- 页面底下铺 `bg-meadow.webp`（很淡的湖和草地，没有太阳），上面盖 28% 页面色。被单据挡住的中间基本是天空，景物只在边缘和底部露出。
- 风：WebGL 着色器重绘背景，一阵阵浅色风带从左往右扫过草地（草微微倒伏、泛亮）。鼠标横向划动从指针处掀起一阵风（最多 4 阵同时存在，两阵至少隔 0.35s）。
- 飘叶：5–10 秒一片，从左往右飘，边飘边翻，同时最多 4 片；被鼠标推开。
- 减弱动效或触屏（无悬停）只画静态风景；页面不可见时停帧；WebGL 不可用时由 CSS 背景兜底。实现：`SceneryField.vue` + `useScenery.ts` + `sceneryMath.ts`（有单测）。

### 5.3 列表（登记簿）

- 单据内：顶部工具栏（搜索框胶囊或输入框、筛选），表头下 2px 墨线，行间 1px `rule`，无竖线、无斑马纹。
- 两行单元格不变：标题行 14px 600（已超时芥黄胶囊跟在后面），第二行「类型　单号」12px `ink-3`；申请人第二行写部门；没有金额写「无」。当前节点用天青胶囊。
- 悬停：整行 `row-hover`，首列左侧 5px 芥黄竖条，行尾显出操作（「处理」用芥黄按钮，其余纸色小按钮）。
- 分页：右对齐，当前页藏青圆 + 芥黄错版。

### 5.4 工作台

```
 ┌ 横幅插画（workbench-banner.webp，高 236，圆角 20，硬投影）──────────────┐
 │  晚上好，李研（展示字 50）                                               │
 │  10 月 26 日 星期一   有 4 张单子等你审批                                │
 └─────────────────────────────────────────────────────────────────────────┘
 ┌ ☀ 待你审批 ─────────── 查看全部待办 ┐  ┌ ◒ 我的申请 ───────── 全部 ┐
 │ 两行单元格 · 申请人 · 金额（展示字） [处理] │  │ ▅▅▅▅▅▅ 状态比例条（实色 + 颗粒）│
 └───────────────────────────────────────┘  │ ■ 审批中 1 / ■ 已通过 3 / …    │
 ┌ ❦ 发起申请 ────────────── 全部类型 ┐  │ ┌ 已通过金额（藏青块 + 错版）┐ │
 │ [插画][插画][插画][插画][插画]          │  │ └ ¥12,800.00 展示字 32 ─────┘ │
 │ 采购申请  差旅申请  报销申请 …（展示字）│  └──────────────────────────────┘
 └───────────────────────────────────────┘  ┌ 🔔 最近通知 ─────── 通知中心 ┐
```

- 两栏：左自适应、右 340，间距 28；1100 以下右栏落到下方。横幅文字压在插画左侧的空白天空上，插画用 `background-position: right 28%`。
- 发起入口：上面一张 4:3 小插画（圆角 12、纸影硬投影），下面展示字单据名 + 12px 说明。悬停抬起 2px、投影换成芥黄。采购 / 差旅 / 报销 / 请假 / 用章用对应插画，其他自定义模板用 `apply-generic.webp`。
- 「待你审批」只在有审批权限时出现；没有时左栏第一张单据是「我的申请」最近 5 条。

### 5.5 申请详情（记忆点）

- 单据最大宽 1040，居中。单据头：类型 + 单号（13px ink-3）、标题（展示字 38）、状态胶囊 + 申请人 + 部门 + 提交时间；右侧金额（展示字 44，右对齐）。终态时单据头右上落章（铁锈、残缺遮罩 `--eas-stamp-mask`、-10° 旋转）。
- 签批栏：一格一块色，格与格之间留 10px 纸缝，每格圆角 14。已办 = 鼠尾草浅底 + 右上一枚「同意」/「驳回」小章；当前 = 芥黄浅底 + 芥黄错版；未到 = 暗纸、文字 ink-3；跳过 = 暗纸「已跳过」。格内：节点名 12px 600 ink-2、处理人展示字 21、时间 / 意见 13px。
- 分段（签批 / 申请内容 / 附件 / 流转记录 / 单据信息）之间虚线；小节标题展示字 21，前面可带两色小图形。
- 底部操作栏：纸底，上沿 `0 -4px 0 shade` 硬投影，高 72；左边一句当前状态（「轮到你审批：财务审批」），右边按钮（驳回 = 铁锈色块，同意 = 藏青色块）。

### 5.6 表单（发起 / 编辑）

- 整个表单是一张单据：单据头（展示字 28 的类型名 + 一行说明；草稿时右上角「草稿」暗纸胶囊和单号），小节之间虚线，小节标题展示字。
- 标签在上、输入框在下，两列网格；输入框纸上留空（`field` 底、1.5px 框线），聚焦墨线框 + 芥黄错版；必填星号铁锈。
- 明细表、报价表用登记簿样式；合计行 `row-hover` 底，金额展示字右对齐。底部操作栏同详情页。

### 5.7 统计

- 页面自己渲染展示字 40 标题 +（个人 / 本部门 / 全企业）胶囊页签（`IndexTabs`），日期区间与刷新在页签同一行右侧。
- 顶部一张单据做「账单行」：3–4 个指标横排，指标名 12px ink-3、数值展示字 36，指标之间虚线分隔。
- 图表各占一张单据，序列色用 chart-1..6，柱子圆角顶；空数据时写清原因和下一步。

### 5.8 登录 / 注册

- 左边是整幅插画（`login.webp`，圆角 20、纸影硬投影），样例单据（纸色、硬投影 8px）压在插画左上的空白天空上。签批栏按第 6 节「流转演示」自动走流程，三格样式与详情页一致，第 ④ 步「已通过」章挂在单据右下沿。插画下方一行 13px：「审批流程」。
- 右边表单直接放在页面底上（背后是风景），品牌在上，「登录」展示字 52，标签在上、输入框高 44，主按钮通栏高 46（藏青色块），演示账号是纸色小卡（硬投影），点了自动填入。
- 分栏可拖动等交互不变（第 6 节）。

### 5.9 空状态、403、404

- 空状态（`ListEmpty`）：居中一张圆形插画（210px，背后芥黄错版圆），展示字 26 标题、一句说明、一个按钮。普通空列表用 `empty-tray.webp`，筛选后无结果用 `empty-search.webp`。
- 403 用 `forbidden.webp`（上锁的文件柜），404 用 `not-found.webp`（断了路线的地图），布局同空状态，按钮「回到工作台」。

## 6. 交互

### Web：鼠标

1. 列表行整行可点进入详情；Ctrl / ⌘ / 中键新标签页打开。
2. 签批栏与流转记录悬停联动；单号悬停复制（「已复制单号」）。
3. 按钮、发起入口、铃铛：悬停抬起、按下沉进投影。
4. 附件区拖入时虚线框变藏青、底色变天青浅。
5. 统计图表悬停显示数值，悬停图例高亮对应序列。
6. 背景见 5.2。

### Web：登录页「流转演示」

三格签批栏（部门负责人 李研、财务审批 吴审、企业负责人 赵总）自动循环四步：①②③ 各停 2400ms，④ 停 3200ms 后淡出 200ms 回到 ①。① 部门负责人处理中；② 部门负责人同意、财务处理中；③ 前两格同意、企业负责人处理中；④ 三格同意，落「已通过」章。刚变成同意的格子播一次盖章（1.15 → 1、透明度 0 → 1，240ms）。

- 鼠标在单据上暂停；移到第 i 格切到「第 i 格处理中」；移开后从当前步继续。
- 单据对读屏隐藏，说明文字可读。减弱动效时停在第 ② 步不自动播放；页面不可见时暂停；卸载时清理计时器。状态机在 `slipDemo.ts`（有单测），只换样式。

### Web：登录页分栏可拖动

不变：分界线两侧 6px 热区、`col-resize`；悬停 / 拖动时 2px 藏青线 + 握把；表单栏最窄 360px，左栏最窄 200px；宽度存 `localStorage`（`eas.auth.formWidth`），双击恢复 540px；方向键 16px、Home / End；880px 以下只显示表单栏。

## 7. 动效

- 只有这几类：对操作的回应（悬停抬起、按下、展开、选中、拖动）、背景的风和飘叶、登录页流转演示、盖章。不做页面载入动画、逐个淡入。
- 时长 120–240ms，缓动 `cubic-bezier(0.2, 0, 0, 1)`。
- `prefers-reduced-motion: reduce` 时所有过渡瞬时完成，章直接显示，背景静止。

## 8. 质量底线

- 对比度：正文 ≥ 4.5:1；色块上的字按第 2 节配色。
- 可点元素 ≥ 32px；768px 以下切抽屉菜单，列表行内操作常显。
- 所有自建可点元素用 `button` / `a`，或补齐 `tabindex` 与回车 / 空格；键盘焦点 2px 墨线外框。
- 1280、1440、1920 宽和 375 宽下都不出现横向滚动条（签批栏、宽表格在单据内部横向滚动除外）。
- 插画都是 WebP，单张不超过约 250 KB；装饰性图片 `alt=""`，首屏以下 `loading="lazy"`，写明宽高或 `aspect-ratio`。

## 9. 移动端（第一版，暂不改）

- 页面底色 `#F2F3F0`，导航栏同底色、黑字；列表卡片白底 12rpx 圆角、无阴影，卡片间距 16rpx。主色 `#3E5C76`，其余见 `mobile/styles/tokens.css`。
- 首页：问候语（宋体）→「待你审批」前 3 条 →「我的申请」状态条 → 发起入口四列网格 → 最近通知。详情页：单据头 + 横向可滚动的签批栏 + 字段区 + 流转记录。tabBar 文字 `#6C777E`，选中 `#3E5C76`。
- 手指交互：
  1. 按压反馈：可点的卡片、列表行、宫格用 `hover-class`（底色变深一档、缩放 0.985，`hover-stay-time` 60ms）。
  2. 左滑操作（自建 `SwipeCell`）：消息左滑「标为已读」；我的申请审批中左滑「催办」「撤回」，草稿左滑「删除」；同一时间只展开一个，点别处或滚动时收起。
  3. 横滑切换标签：待办 / 已办、我的申请的状态筛选，横向位移 > 60px 且大于纵向 1.5 倍时切换，选中块随之滑动（200ms）。
  4. 滑动同意（自建 `SlideConfirm`）：拖到 ≥ 90% 才提交，中途松手弹回，成功短振动；「驳回」保持按钮。
  5. 底部面板下拉关闭：下拉超过 120rpx 或快速下划时关闭，否则回弹。
  6. 长按单号复制；签批栏横向滚动，点格子展开该节点意见；保留下拉刷新、上拉加载。
- 触控目标 ≥ 88rpx。
